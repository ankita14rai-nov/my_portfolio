Kavach - Voice Activated Alert System

An innovative safety application designed specifically for women's security and personal safety. Kavach is a voice-activated alert system that allows users to trigger emergency alerts by voice commands without needing to physically interact with their devices. The system instantly notifies emergency contacts with real-time GPS location, sends alerts to nearby registered safe zones, and integrates with local law enforcement. Features include voice recognition technology, automated SMS/call alerts, location sharing, and a comprehensive emergency response network.
